## [FASE 6] PWA-AGENT -> ORCHESTRATOR

- **Selesai**: PWA installable TANPA dependensi npm baru dan TANPA push notification (PRD baris 321-329 bagian 15, item "PWA dan notifikasi push" — bagian push sengaja ditunda, menyusul). (1) `public/manifest.webmanifest`: name "Forum Komunitas", short_name "Forum", deskripsi bahasa Indonesia, start_url "/", scope "/", display "standalone", background_color & theme_color gelap netral `#0b0f1a`, lang "id", dir "ltr", satu entri ikon SVG (`sizes: "any"`, `type: "image/svg+xml"`, `purpose: "any maskable"`) — SVG sizes "any" dihitung valid untuk installability Chrome, tidak perlu PNG. (2) `public/icon.svg`: viewBox 0 0 24 24, rounded-square biru `#3b82f6` + gelembung chat putih (path persis logo header `M7.9 20A9 9 0 1 0 4 16.1L2 22Z`) + tiga titik biru di dalamnya (posisi ala lucide message-circle-more: 8/12/16, y=12); gelembung diskalakan 0.85 di sekitar pusat agar aman dimasker (purpose maskable) dan tetap terbaca di ukuran kecil. (3) `public/sw.js` (vanilla, tanpa Workbox): install precache minimal `["/", "/offline.html"]` (per-URL try/catch + `cache: "reload"`) + `skipWaiting`; activate hapus semua cache versi lama + `clients.claim`; fetch handler ber-guard berlapis — **hanya GET**, **hanya same-origin** (mengeliminasi supabase.co & domain lain), **/api/* selalu lewat** — lalu: navigasi dokumen (`request.mode === "navigate"`) **network-first** (gagal jaringan → `/offline.html` dari cache; halaman sengaja TIDAK di-cache karena semua rute force-dynamic & per-pengguna), **cache-first HANYA** untuk `/_next/static/*` (filename content-hashed) dan `/icon.svg` (hanya respons ok + type basic yang disimpan); sisanya (RSC prefetch `?_rsc=`, `/_next/image`, favicon, dll.) tidak diintercept sama sekali. (4) `public/offline.html`: halaman statis inline-styled tema gelap (`#0b0f1a`, aksen `#3b82f6`, `color-scheme: dark`), ikon SVG sama dengan icon.svg, teks "Kamu sedang offline — Periksa koneksi internetmu, lalu coba muat ulang halaman." + nama "Forum Komunitas", tombol "Coba lagi" (reload) + auto-reload saat event `online` (6 baris vanilla JS, tanpa dependensi). (5) `app/layout.tsx`: `manifest: "/manifest.webmanifest"`, `appleWebApp { capable: true, statusBarStyle: "black-translucent", title: "Forum" }`, `icons` → `/icon.svg` (icon + apple) di metadata; `themeColor: "#0b0f1a"` via `export const viewport: Viewport` (pola Next 15 — themeColor TIDAK di metadata). (6) `components/PwaRegister.tsx` ("use client"): registrasi `/sw.js` saat mount (catch diam — tidak fatal), deteksi `beforeinstallprompt` (preventDefault mini-infobar bawaan) → banner diskrit "Pasang aplikasi Forum" (fixed di atas BottomNav mobile / pojok kanan-bawah desktop, z-40) dengan tombol "Pasang" (`deferredPrompt.prompt()` + tunggu `userChoice`) dan tombol tutup (SVG X); outcome accepted/dismissed maupun event `appinstalled` → flag `localStorage["pwa-install-dismissed"]="1"` dan banner tidak tampil lagi; render null bila SW tidak didukung / sudah standalone (termasuk iOS `navigator.standalone`) / flag terpasang. (7) `app/(main)/layout.tsx`: `<PwaRegister />` dirender di antara `<BottomNav>` dan `<footer>` (sebelum penutup `</div>` luar).

- **Asumsi / keputusan**:
  1. Caching sengaja MINIMAL dan konservatif (keamanan > performa): halaman tidak pernah di-cache (semua rute force-dynamic & per-pengguna — menyajikan HTML basi berisiko mencampur sesi), cache-first hanya untuk `/_next/static/*` (filename content-hashed = immutable) dan `/icon.svg`. RSC prefetch `?_rsc=` dan `/_next/image` tidak diintercept agar payload navigasi & gambar selalu segar.
  2. Guard fetch berlapis dan selalu sinkron sebelum `respondWith`: (a) `method !== "GET"` → return (server action POST otomatis lolos), (b) `url.origin !== location.origin` → return (supabase.co, avatar/gambar eksternal lolos), (c) pathname `/api/*` → return. Tidak ada jalur kode yang menyentuh ketiga kategori itu.
  3. Precache `/` tetap dilakukan sesuai instruksi walau tidak pernah disajikan (navigasi network-first dan halaman tidak di-cache) — sekadar memenuhi precache minimal; boleh dihapus dari `PRECACHE_URLS` tanpa efek perilaku bila dianggap pemborosan.
  4. Ikon hanya SVG `sizes "any"` `purpose "any maskable"` — Chrome menerima SVG sizes "any" untuk installability; warning Lighthouse "no PNG icon" aman diabaikan. Maskable disediakan lewat latar rounded-square full-bleed + gelembung diskalakan 0.85 (di luar safe-zone maskable hanya ujung ekor kecil gelembung). Kalau nanti butuh splash iOS sempurna, tambah PNG tanpa menyentuh kode lain.
  5. `statusBarStyle: "black-translucent"` (konten menempel di bawah notch di iOS standalone) + `appleWebApp.title "Forum"` sesuai instruksi; themeColor viewport `#0b0f1a` konsisten dengan manifest.
  6. Banner install memakai `beforeinstallprompt` standar Chromium. iOS Safari tidak punya padanan programatik (event tidak pernah fire → banner tidak muncul di iOS; pengguna install manual via Share > Add to Home Screen) — diterima sebagai batasan platform, bukan bug.
  7. Banner fixed: mobile `bottom: calc(4rem + safe-area)` sehingga tidak menutupi BottomNav (z-30, tinggi ~56px); md+ pojok kanan-bawah (BottomNav hidden). z-40 di atas nav/header. `role="status"` agar terumumkan ke pembaca layar.
  8. `skipWaiting` + `clients.claim` → SW baru langsung aktif tanpa menunggu reload kedua; karena cache konservatif (tidak ada HTML di cache), risiko versi campur kecil. Precache memakai `cache: "reload"` agar tidak menyalin respons HTTP cache browser.
  9. offline.html auto-reload saat event `online` (UX kecil tanpa dependensi); bila dianggap agresif, hapus listener-nya — tombol "Coba lagi" tetap berfungsi. `cache.match("/offline.html")` di fallback navigasi selalu cocok karena precache di install; bila precache offline gagal (jarang), ada fallback Response 503 teks.
  10. Emoji pada teks banner ("📱 Pasang aplikasi Forum") sesuai instruksi tugas; tombol tutup memakai SVG X (bukan karakter) untuk konsistensi dengan ikon lain di proyek.

- **Cara memeriksa**:
  1. `npm run build` lulus (tidak ada file di luar daftar kepemilikan; next.config.ts tidak berubah; tidak ada dependensi baru di package.json).
  2. Deploy ke https://www.chatasiqque.my.id → DevTools > Application > Manifest: name "Forum Komunitas", short_name "Forum", display standalone, theme/background #0b0f1a, ikon /icon.svg valid; > Service Workers: /sw.js "activated and running", scope "/"; > View Source pada <head>: ada <link rel="manifest">, <meta name="theme-color" content="#0b0f1a">, apple-web-app meta.
  3. Lighthouse (kategori PWA, mobile): "Installable" lolos — manifest + service worker dengan fetch handler + offline fallback 200.
  4. Uji offline: DevTools > Network > Offline → reload → muncul halaman gelap "Kamu sedang offline …" + "Forum Komunitas" (dari cache /offline.html); kembalikan ke Online → halaman otomatis termuat ulang. Pastikan juga tab biasa (bukan offline) tidak pernah menyajikan halaman dari cache (selalu dari Network).
  5. Uji aset: dengan SW aktif, tab Network menunjukkan `/_next/static/*` dan `/icon.svg` berlabel "ServiceWorker" (cache-first), sedangkan dokumen dan request Supabase tetap "Network"/fetch biasa.
  6. Uji banner: Chrome desktop/Android yang belum pernah dismiss → banner "Pasang aplikasi Forum" muncul di atas bottom nav; klik "Pasang" → dialog install native; setelah install/dismiss ATAU klik tutup → reload, banner tidak muncul lagi (localStorage `pwa-install-dismissed` = "1"); hapus key itu di DevTools > Application > Local Storage untuk menampilkan lagi.
  7. REGRESI PENTING (harus lulus semua): login/logout, buat post, komentar, vote, upload gambar, halaman admin — semuanya normal dengan SW aktif; di tab Network pastikan request `*.supabase.co`, semua POST (server action), dan `/api/*` tidak berlabel "ServiceWorker" (lewat tanpa intercept).
  8. Install sebagai PWA (ikon install di omnibox Chrome / menu "Install app") → jendela standalone judul "Forum", tema gelap #0b0f1a, ikon gelembung chat biru; di dalam mode standalone banner install tidak muncul; uninstal lalu hapus flag untuk menguji ulang.
